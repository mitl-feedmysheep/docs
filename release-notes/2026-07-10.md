# 2026-07-10

## 백엔드 (backend)

**기도제목/리딩플랜 푸시 중복 발송 수정**
- 증상: 기도제목 알림이 하루에 9시, 10시 두 번 발송됨 (배우자 계정도 동일 증상)
- 원인: `@Scheduled(cron = "0 0 * * * *")`(매시 정각) + 애플리케이션 코드로 "지금이 9시대인가"를 재확인하는 구조라, 09:00:00~09:59:59라는 60분짜리 매칭 구간이 생기고 그 구간 안에서 스케줄러가 두 번 틱하면(재시작 직후 클럭 흔들림 등) 중복 발송됨
- 수정: 매시간 + 조건 재확인 대신, 하루에 정확히 한 번만 도는 daily cron으로 전환
  - `DailyPrayerPushScheduler`(구 `HourlyPrayerPushScheduler`): `cron = "0 0 9 * * *", zone = "Asia/Seoul"`
  - `DailyReadingPushScheduler`: `cron = "0 0 8 * * *", zone = "Asia/Seoul"`
  - 구독자별 timezone 필터링 로직(`filterByCurrentHour`, `isLocalHour`) 제거 — 현재 전 사용자가 한국 시간대이므로 불필요한 조기 추상화였음. 여러 나라 교회 지원이 실제로 필요해지면 그때 재도입
  - 미사용 `Clock` 빈 제거
- 부수 수정: `DailyReadingPushScheduler`의 `LocalDate.now()`가 컨테이너 기본 timezone(UTC) 기준이라, KST 8시 실행 시 실제로는 전날 날짜로 계산되던 버그 → `LocalDate.now(Asia/Seoul)`로 수정
- 리딩플랜 알림 문구 변경: 타이틀 "오늘의 말씀, 같이 읽어요 📖", 본문 `{플랜이름} · {오늘 읽을 분량}`
