# 최근 작업 업데이트 (2026-06-20)

## 1. 리딩지저스 (성경통독 플랜) — web-app + backend

### 무엇을
부서별로 관리자가 성경통독 플랜을 설정하면, 부서원이 매일 오늘의 본문을 확인하고 완독 여부를 기록하는 기능.

### 어떻게
- **backend**: `EducationProgram` 도메인을 리딩플랜용으로 확장. 읽기 요일을 비트마스크로 관리. 오늘 읽기 조회, 완독 토글, 내 진도(달력 + 누적 일수), 날짜별 부서 완독 인원 API 추가.
- **web-app**:
  - `/reading` — 오늘 본문 확인 + 날짜 탐색 + 완독 토글 + 날짜별 부서 완독 인원 표시
  - `/reading/progress` — 달력 뷰로 내 완독 이력 + 부서 완독 현황 배너
  - 홈 화면 상단에 BookMarked 아이콘 추가, 미완독 시 빨간 점 뱃지
  - 오늘 읽기 페이지에 요약 이미지(R2 업로드) 노출 + 라이트박스 지원

### 특이사항
- 리딩플랜은 부서 단위로 운영. 어드민에서 플랜 활성화 여부와 시작일을 설정.
- 비트마스크: 일(1), 월(2), 화(4), 수(8), 목(16), 금(32), 토(64)

## 2. 공지사항 기능 — web-app + backend + admin

### 무엇을
부서 관리자가 어드민에서 공지사항을 작성하고, 유저 앱 홈에서 확인하는 기능. 푸시 알림 예약 발송 포함.

### 어떻게
- **backend**: `announcement` 테이블. `send_at`, `is_sent`, `push_enabled` 컬럼. 매 5분마다 `AnnouncementPushScheduler`가 `send_at <= now AND is_sent=false` 조건으로 폴링해 웹푸시 발송 후 `is_sent=true` 업데이트.
- **admin**: 공지사항 작성/수정/삭제 UI. 5분 단위 발송 예약 시각 선택.
- **web-app**: 홈 화면 공지사항 섹션 (최근 2개), 목록/상세 페이지.

### 오늘 변경
- 발송 예약 분 단위를 10분 → 5분 단위로 변경
- ConfirmDialog 삭제 확인 시 포커스가 "취소"로 잡히는 버그 수정 (`autoFocus` 추가)
- 어드민 스케줄러 주기: 매분 → 매 5분 (`0 */5 * * * *`)

## 3. 앱 푸시 알림 — web-app + backend

### 무엇을
Web Push API(VAPID)를 이용한 웹푸시 구독/해제 및 기도제목·공지사항 알림 발송.

### 어떻게
- **backend**: `push_subscription` 테이블에 endpoint + auth key 저장. `PushSubscriptionTopic`으로 토픽별 구독 관리.
- **web-app**: 앱 진입 시 최초 1회 바텀 시트 프롬프트 (권한 default 상태일 때만). MY 탭 > 알림 설정 페이지.
