# 주보 기능 설계

## 개요

교회 주보(사진)를 부서 단위로 관리하는 기능. 어드민에서 업로드, 웹앱에서 조회.

## 왜 만들었나

- 매주 주보를 앱에서 바로 볼 수 있도록
- 지난 주보 히스토리 보관

## 구현 방식

### 데이터 저장

기존 `announcement` 테이블에 `type = 'BULLETIN'`으로 저장. 별도 테이블 불필요.

| 필드 | 값 |
|------|-----|
| entity_type | DEPARTMENT |
| entity_id | departmentId |
| type | BULLETIN |
| title | "YYYY년 M월 N주차 주보" (자동 생성) |
| body | title과 동일 (푸시 알림 body로 사용) |
| send_at | 즉시 or 예약 시각 |
| push_enabled | 어드민에서 선택 |

미디어: 기존 `media` 테이블, `entity_type = 'ANNOUNCEMENT'`, `entity_id = bulletinId`

### "이번 주 주보" 판단 기준

`created_at`이 이번 주(월~일) 안에 있는 BULLETIN 중 가장 최신 1개.
별도 날짜 범위 컬럼 없음.

### DB 변경

```sql
ALTER TABLE announcement MODIFY COLUMN body TEXT NULL;
```

### 백엔드 변경

- `AnnouncementJpaEntity.body`: nullable 허용
- `AnnouncementPushScheduler.buildPayload()`: null body 방어 처리

### 어드민

- 사이드바 "주보 관리" 메뉴 추가
- `/manage/bulletin` 페이지: 목록 + 업로드 다이얼로그
- 업로드 폼: 년도 / 월 / 주차 선택 → title 자동 생성, 이미지 업로드, 푸시 체크박스
- API 라우트: `/api/bulletins/`, `/api/bulletins/[id]/`, `/api/bulletins/[id]/media/`

### 웹앱

- 홈 화면: 이번 주 주보 카드 (공지사항 위, 없으면 미표시)
- `/announcements` 탭: 공지사항 | **주보** | 전체알림
- `/bulletins/:id`: 이미지 전용 상세 뷰어 (라이트박스)
- 진입: 홈 카드 탭 또는 주보 탭 리스트 탭
