# 교회 숨김 플래그 (is_hidden)

## 배경 / 목적

웹앱 신규 가입자가 "교회 편입 요청" 화면(`RequestChurchPage.tsx`)에 진입하면 `GET /churches/all` 로 **전체** 교회 목록을 받아 보여준다. 이 목록에 테스트용으로 만든 교회 등 실사용자에게 노출되면 안 되는 항목이 그대로 섞여 나온다.

`church` 테이블에는 노출 여부를 제어할 컬럼이 없고(`name/location/number/homepage_url/description` + soft delete 필드뿐), 어드민에도 교회 생성 UI만 있고 수정 UI가 없다.

## 결정 사항

- `church` 테이블에 `is_hidden BOOLEAN NOT NULL DEFAULT false` 컬럼 추가
- `is_hidden = true`인 교회는 **웹앱 편입 요청 목록(`GET /churches/all`)에서만** 제외한다. 이미 소속된 회원의 화면(`GET /churches`, 교회 전환 등), 어드민의 다른 모든 화면·쿼리는 영향받지 않는다 — 둘 다 `ChurchMember` 관계나 `churchId` 스코프로 조회하는 별개의 쿼리이기 때문.
- 인덱스: `church` 테이블은 row 수가 적고 기존에도 `deleted_at` 등에 인덱스가 없어(PK만 존재), `is_hidden`에도 별도 인덱스 추가하지 않음.
- 토글은 어드민의 새 "교회 목록" 탭(`system/church`, `SYSTEM_ADMIN_MEMBER_ID` 계정 전용)에서 관리. 백엔드 API를 거치지 않고 어드민이 Prisma로 DB에 직접 update.

## 구현 범위

### DB
```sql
ALTER TABLE church
  ADD COLUMN is_hidden TINYINT(1) NOT NULL DEFAULT 0
  COMMENT '숨김 여부 (교회 편입 요청 목록에서 제외)'
  AFTER description;
```
Doppler 환경변수 변경 없음. DB 스키마 변경은 사용자가 직접 실행(에이전트는 read-only 접속만 허용).

### Backend
- `domain/model/Church.java` — `isHidden` 필드 추가
- `adapter/out/persistence/entity/ChurchJpaEntity.java` — `is_hidden` 컬럼 매핑 (`Department.isDefault` 패턴과 동일하게 `Boolean` + `@Builder.Default = false`)
- `adapter/out/persistence/mapper/ChurchPersistenceMapper.java` — 양방향 매핑 추가
- `adapter/out/persistence/repository/ChurchJpaRepository.java` — `findAllByIsHiddenFalse()` 추가
- `adapter/out/persistence/ChurchPersistenceAdapter.findAllChurches()` — `findAll()` → `findAllByIsHiddenFalse()` 로 변경 (이 메서드의 유일한 호출부가 `GET /churches/all`이므로 안전)
- 테스트: `ChurchPersistenceMapperTest`에 `isHidden` 필드 검증 추가

### Admin
- `prisma/schema.prisma` — `church` 모델에 `is_hidden Boolean @default(false)` 추가 (`/// 숨김 여부...` 코멘트)
- `app/api/system/churches/route.ts` — select에 `is_hidden` 추가 (기존 권한관리 탭 드롭다운에는 영향 없음, 신규 "교회 목록" 탭에서 재사용)
- 신규 `app/api/system/churches/[id]/route.ts` — `PATCH`, `SYSTEM_ADMIN_MEMBER_ID` 전용, `{ isHidden: boolean }` → `is_hidden` 업데이트
- `app/system/church/system-church-client.tsx` — 탭 4개로 확장: 교회 생성 / **교회 목록**(신규) / 권한 관리 / 비밀번호 초기화. 신규 탭은 `deleted_at IS NULL` 교회 목록 + 행별 `Switch` 토글

### Web-app
- 코드 변경 없음 (`GET /churches/all` 그대로 호출, 백엔드가 필터링)
